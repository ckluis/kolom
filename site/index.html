02 Multiple displays

And every display gets its own strip.

While Kolom manages, it sets your displays corner to corner — a display staircase, an idea from Defi (MIT) — so columns slide cleanly off every edge. Your pointer still crosses monitors exactly as your desk is laid out.

Unplug a monitor and its windows join the main display. Plug it back in and they go home.

03 Agents

Your agent can drive it, too.

kolomctl and a local MCP server let your coding agent read the layout and build Terminal grids for you.

$ claude mcp add --scope user kolom -- ~/.local/bin/kolomctl mcp
  • Local. The MCP server runs on your Mac, beside Kolom.
  • Your call. Moving windows stays off until you opt in.
  • Same grids. “3×2 terminals” works from your agent, too.

05 Install

Hand this to your agent.

Paste one line into the coding agent on your Mac. It reads the guide, builds Kolom from source, and walks you through the permission.

Read https://github.com/ckluis/kolom/blob/main/INSTALL-WITH-AN-AGENT.md and follow it.

Or do it yourself

$ git clone https://github.com/ckluis/kolom && cd kolom && ./scripts/install.sh
  • Alpha. Usable day to day, still being hardened.
  • macOS 13 or later. Tested on Apple silicon.
  • Ask Kolom needs macOS 26 with Apple Intelligence.
  • Builds from source. No notarized download yet.
  • Needs Accessibility permission to move your windows.
  • A guide is built in. Click the ? in the rail.
