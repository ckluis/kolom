# Implementation provenance

Kolom's native source and tests in this repository are original, with one adaptation: Defi's display staircase and pointer mapping (MIT) in `Sources/KolomCore/DisplayArrangement.swift`, listed in [THIRD-PARTY-NOTICES.md](../THIRD-PARTY-NOTICES.md). No Paneru, niri, PaperWM, yabai, or AeroSpace source files, code fragments, build artifacts, or runtime packages are included or linked.

Paneru and niri are product / interaction references: horizontal window strips, viewport navigation, and the concept of leaving a small window sliver visible when macOS prevents completely off-screen positioning. Reference implementations were consulted to understand macOS behaviour, not incorporated into Kolom.

The implementation uses Apple's AppKit, SwiftUI, CoreGraphics, ApplicationServices / Accessibility, Carbon hot-key APIs and, optionally on macOS 26, FoundationModels, all supplied by the macOS SDK. There are no third-party Swift package dependencies or downloaded icon packs. Native application icons are read from the applications installed on the user's Mac. Kolom's own application icon is generated by this project's drawing script.

Apart from the Defi adaptation, no third-party source is included. Any future external source, dependency, or redistributed asset must have its license reviewed before adoption. Behavioural inspiration alone does not authorize incorporating that project's code.
